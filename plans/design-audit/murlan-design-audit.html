The core is in good shape: the engine's refusal ladder, applyOrForward, gameOwnership, the seat ledger, the landing clock, decide() and settle are deep modules and should be left alone (full list at the end). The problems sit at the edges. Logic that both transports share lives behind React providers or Socket.IO handlers. Ports exist in some places and not in their siblings. And many safeguards are source scans standing in for a seam that doesn't exist yet.

Cross-cutting themes

Several auditors reached the same seam from different sides. These are the highest-leverage moves, because one change closes findings in several areas at once.

1 · Match lifecycle has no module

D-F2 · D-F5 · D-F9 · S-F4 (nextRound) · T11

Start a match, fold a round, roll forward and deal the next round are written three times: GameContext, the server (dealVotedRound + newTable), and a "verbatim copy" in tests/helpers/offlineMatch.ts whose banner says changes must be carried by hand.

One pure lib/game/matchFlow.ts (startMatch / commit / dealNext). That removes ~70 mirrored test lines and two redundant offline state slots, collapses 3 rematch-or-new-game branches into 1, moves teamsSingleRound to node --test, and makes "harness passes against a stale copy" impossible.

2 · "What just happened" is reconstructed by diffing

D-F3 · D-F6 · D-F12 · U-F3 · C-F6 · #1603 partly

GameState has no record of the last move, so the UI diffs passCount, the online context keeps three refs to detect exchange edges, and a turn|pass|combo key needs its own collision-hunting harness.

A lastMove {seq, seat, kind, closedTrick} written by every transition makes keys collision-free by construction, deletes trickClosedWithWinner, the edge refs and the collision harness, and turns the opening predicates into one-liners. A stateFixture() builder must land first: 118 hand-built GameState literals live in 99 test files.

3 · The game layer's output port is all of Socket.IO

S-F1 · S-F10 · S-F13 · T3 · T4

About 44 parameters thread io: SocketServer through the game layer; 11 test files hand-roll an io stub with as unknown as SocketServer (20 casts); module setters exist only to dodge import cycles.

A TableOutbox + Presence port with one Socket.IO adapter and one recording adapter. Rule tests can then leave tests/integration (Postgres + socket) for tests/server, the setters go away, the import graph points one way, and emits become type-checked at one seam.

4 · active_games and the table registry have no owner

S-F2 · S-F12 · S-F14 · T4

The live-table Map is module-global (23 test files mutate it); table persistence is raw drizzle in three modules; tests patch db.query.activeGames.findFirst with t.mock.method 41 times.

An ActiveGameStore (Postgres + in-memory adapters: a real seam) and a private TableRegistry. This removes ~41 monkeypatches, keeps write-ordering inside one module, writes the 3-step delete order once, and turns tableOwnership's regexes into type facts.

5 · Refusals travel on two channels

S-F3 · D-F7 · U-F1 · S-F17

A refusal is emitted and returned separately, the codes are string, three engine transitions use three error modes, and the UI keeps its own refusal copy.

A RefusalCode union plus return refuse(channel, code) as the only way to refuse, and applyMove(state, seat, move) returning {ok} | {ok:false, code}. The silent-ok:true bug becomes unwritable, ~20 emit/return pairs and the identity maps disappear, and client/server code drift becomes a compile error.

6 · Randomness and time are only partly injectable

D-F11 · S-F9 · T8 · T9

Deals read globalThis.crypto; tests patch globals in four different ways. gameTimers has a Clock, but exchange visibility, seat holds, idempotency TTL and rate windows read Date.now(). Config arrives through 24 MURLAN_* env vars written 94 times by tests.

A RandomSource argument, clock in TableDeps, and createApp(config). This deletes 4 global patches, ~51 env writes and timerEnvIsLive, lets integration tests advance a fake clock instead of sleeping, and removes the two-clock disagreement class.

7 · Client contexts have no test seam

T1 · T2 · C-F5 · C-F8 · C-F11 · #1602 partly

No context exports its Context or a provider for tests, so screen tests mock the modules: 97 context mocks, 46 mocks of @/lib/accessibility (which already has a public setter), 17 hand-made socket fakes whose off(){} is a no-op.

An exported AppProviders taking the HTTP and socket adapters, a renderApp harness and one typed FakeSocket. This deletes ~125 context/transport mocks and the 46 accessibility mocks, and every screen test then exercises the real provider wiring.

8 · Table geometry is locked inside components

U-F2 · U-F4 · U-F9 · U-F16 · #1604 partly

Hand-row layout is pure arithmetic inside a 22-prop component, computed in three parallel loops; a test re-implements it. TableGeometry mixes frame and game state and is spread into a 25-entry dependency array.

A pure layoutHandRow() and tableLayout(). This is the biggest testability gain in the UI: half of handClearance/handTapStrips become node tests, the three loops become one, and "a throw leaves from where the card wasn't drawn" becomes impossible. Optionally placing sections absolutely ends model-vs-flexbox disagreement.

9 · HTTP has no shared contract

S-F6 · S-F8 · C-F7 · T5

Socket events are typed end to end; HTTP isn't. The client hard-codes ~50 /api paths and 30 query keys; one key is typed two ways; there are three fetch clients; routes.ts is 1041 lines with req.session.userId! 26 times.

A shared/http.ts contract, a declarative RouteSpec with an access field, and a client lib/api.ts + query table. Renamed fields become compile errors, the auth guard becomes data instead of a scan, and invalidation sets are named once.

10 · Source scans standing in for seams

T5 · T6 · U-F8 · U-F11 · U-F13 · L-F8

A 463-line hand-written JS lexer, 13 private import regexes, a test that finds JSX children by indentation, a test that regex-parses bash out of ci.yml, and memo comparators kept complete by parsing interface text.

Lint-shaped rules move to eslint (editor errors instead of test runs); single-path rules become typed seams; the lexer goes to the TS AST. Roughly 15–20 scan tests and ~740 lexer lines can go, and the "a scan falls to a decoy" class shrinks.

11 · The loop's core is pure; its edges are not yet

L-F1 · L-F2 · L-F3 · L-F4 · L-F7 · residue of #1605/#1606/#1608

decide() and settle are good. But queue-loop.mjs is still 1706 lines with ~555 lines of adapters; phase is computed in four places and bridged by LOOP_PHASE; gh is reached from ~15 sites through 7 argv-level fakes; tests chdir.

A github.mjs with two adapters (with --repo made structural), a pure phaseOf(facts), a session-env.mjs, and ports grouped by dependency. queue-loop.mjs shrinks to ~500 lines, 7 fakes become 1, and "a fake tracker hides a missing commit" goes away.

12 · gameEngine.ts surface and placement

D-F13 · D-F14 · D-F15 · T15

1525 lines, about ten responsibilities, and 16–17 exports with no production caller (tests reach below the deep interface). Animation timelines and React hooks live in lib/game, and the server imports pose geometry with exchange timing.

Split into cards / combinations / legalPlays / round / exchange / match; only rules in lib/game. The CLAUDE.md "a rule lives in gameEngine.ts" invariant must be reworded first.

Why yesterday's audit didn't catch all of this

  • Closed tickets fixed an instance, not the class. #1597 "one move-commit path" closed, yet six open-coded publish sequences remain (S-F10). #1596 gave the engine refusal codes, but the GIOCA ladder still copies them (U-F1). #1598 built the table round trip; restore still derives the verdict separately (D-F4). #1600 made gameTimers' clock injectable; five other modules still read Date.now() (S-F9). #1605/#1606/#1608 narrowed the loop's adapters; gh is still reached from ~15 sites (L-F3).
  • Each auditor samples. About 55–80 files per auditor against ~95k source lines, so the files read differ from run to run.
  • The split differed. Today's six areas included a dedicated test-architecture lens, which produced the mock/scan findings (T1–T17) that no area lens sees.

To converge: give each auditor an assigned file manifest, pass in open tickets and the last report, and let deterministic tools (jscpd, madge, knip) cover duplication, cycles and dead exports.
