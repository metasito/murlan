Fix: “Con Amici” screen layout — match “Gioca VS AI” as the reference
Root problem: The “CREA STANZA” card is too narrow to contain its children. The Modalità toggle row (Libera / Coppie) and the Giocatori number row (2 / 3 / 4) are wider than the card they sit inside, causing visible overflow. This is a flex/width constraint issue inside the left panel card.
Instructions:
1.	Open `app/(online)/index.tsx`. This is the “Con Amici” screen.
2.	The overall screen uses a two-column side-by-side layout. The left column (“CREA STANZA”) and right column (“ENTRA IN UNA STANZA”) must be wrapped in a `MenuLayout` component (established in the design system plan), exactly the same way `app/lobby.tsx` (“Gioca VS AI”) wraps its content. Do not use a fixed width on either column — use `flex: 1` on both so they share available space equally and never overflow their parent.
3.	The “CREA STANZA” section must be wrapped in a `MenuCard` component with the title prop set to “CREA STANZA”. The `MenuCard` must have `width: '100%'` so it fills its flex column, not a hardcoded pixel width.
4.	Inside the “CREA STANZA” `MenuCard`, the Modalità row (Libera / Coppie selector chips) and the Giocatori row (2 / 3 / 4 selector chips) must be styled exactly like the “N° GIOCATORI” and “MANCHE” selector rows in `app/lobby.tsx`. Specifically: each row must use `flexDirection: 'row'`, `flexWrap: 'wrap'`, and `gap` spacing between chips. Each chip must NOT have a fixed pixel width — use `paddingHorizontal` only, so the chip sizes itself to its label and never forces overflow.
5.	The label on the left of each row (“Modalità”, “Giocatori”) and the chips to the right must NOT be on a single `flexDirection: 'row'` that forces the chips to compete for width with the label. Instead, stack the label above the chip row (`flexDirection: 'column'`), exactly as “N° GIOCATORI” and “MANCHE” are laid out in the “Gioca VS AI” screen — label on top, chip row below.
6.	The “Crea Stanza” action button inside the card must be a `MenuButton` with `variant="primary"` and `fullWidth={true}`, identical to the “Inizia Partita” button in “Gioca VS AI”.
7.	The “ENTRA IN UNA STANZA” right column must also be wrapped in a `MenuCard` with `width: '100%'`. The “Inserisci codice stanza” button inside it must be a `MenuButton` with `variant="secondary"`.
8.	The page title “Con Amici” and the back chevron header must have the same top padding and font style as the “Gioca VS AI” screen header. Use `useSafeAreaInsets()` for the top padding — do not hardcode it.
9.	Do not change any navigation logic, socket events, room creation logic, or game mode values. Only change the layout, wrapper components, and styling to match the “Gioca VS AI” reference screen.
