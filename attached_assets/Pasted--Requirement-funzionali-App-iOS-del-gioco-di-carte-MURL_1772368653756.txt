## 📱 Requirement funzionali – App iOS del gioco di carte “MURLAN”

Di seguito trovi una **specifica funzionale strutturata per lo sviluppo iOS**, pensata per essere consegnata a un team di sviluppo (Swift / SwiftUI / UIKit + backend online).

---

# 1️⃣ Overview del Prodotto

**Nome gioco:** MURLAN
**Piattaforma:** iOS (iPhone, opzionale iPad)
**Modalità di gioco:**

* 2 giocatori (1 vs 1)
* 3 giocatori (tutti contro tutti)
* 4 giocatori:

  * Tutti contro tutti
  * 2 vs 2 (modalità a coppie)
* Online:

  * 1 vs 1
  * 2 vs 2 (coppie)

---

# 2️⃣ Regole del Gioco – Specifica Logica (Game Engine)

> ⚠ Nota: Le regole sotto sono formalizzate per essere implementabili a livello di codice.

## 2.1 Mazzo

* Mazzo da 54carte standard 
* Semi: ♠ ♥ ♦ ♣
* Valori: 2–10, J, Q, K, A
* Ordinamento di forza (dal più forte al più debole):

```
Joker colorato > joker Bianco nero >2 > A > K > Q > J > 10 > 9 > 8 > 7 > 6 > 5 > 4 > 3 
```

Il 2 è la carta più forte.

---

## 2.2 Distribuzione

Numero di carte per giocatore:

| Giocatori | Carte per giocatore  |
| --------- | -------------------- |
| 2         | 26                   |
| 3         | 17 (1 carta esclusa) |
| 4         | 13                   |

Distribuzione casuale.

---

## 2.3 Obiettivo del gioco

Essere il primo giocatore (o coppia) a rimanere senza carte.

---

## 2.4 Turni di gioco

* Inizia il giocatore con il **3 di cuori (♥3)**.
* Turnazione in senso orario.
* Ogni turno il giocatore può:

  * Giocare una combinazione valida
  * Passare

---

## 2.5 Combinazioni valide

Il motore di gioco deve validare le seguenti combinazioni:

### 1️⃣ Carta singola

* Una carta qualsiasi

### 2️⃣ Coppia

* Due carte dello stesso valore

### 3️⃣ Tris

* Tre carte dello stesso valore

### 4️⃣ Scala (minimo 3 carte)

* Carte consecutive
* No 2 nelle scale
* No salti

Esempio valido:
7-8-9
10-J-Q-K

Non valido:
Q-K-A-2 (2 non ammesso)

---

## 2.6 Regole di risposta

Il giocatore deve:

* Giocare **stesso tipo di combinazione**
* Giocare combinazione di **valore superiore**

Esempi:

* Se viene giocata coppia di 9 → posso giocare coppia di J
* Se viene giocato singolo K → posso giocare singolo A o 2

---

## 2.7 Chiusura turno (presa)

Quando:

* Tutti i giocatori passano consecutivamente tranne uno

Allora:

* Il turno si resetta
* Chi ha vinto la presa ricomincia con qualsiasi combinazione

---

## 2.8 Fine partita

Quando:

* Un giocatore termina le carte

Modalità:

### Tutti contro tutti

* Il primo che finisce è vincitore
* Ranking opzionale: 1°, 2°, 3°, 4°

### Modalità coppie

* Vince la coppia del primo giocatore che termina le carte

# 3️⃣ Architettura Logica del Gioco

## 3.1 Entità principali (Model Layer)

### Card

```swift
struct Card {
    let suit: Suit
    let rank: Rank
}
```

### Player

```swift
struct Player {
    let id: UUID
    var hand: [Card]
    var isOnline: Bool
    var team: Team?
}
```

### GameState

```swift
struct GameState {
    var players: [Player]
    var currentTurnIndex: Int
    var lastPlayedCombination: Combination?
    var passCount: Int
    var gameMode: GameMode
}
```

### Combination

```swift
enum CombinationType {
    case single
    case pair
    case triple
    case straight
}

struct Combination {
    let type: CombinationType
    let cards: [Card]
    let valueRank: Rank
}
```

# 4️⃣ Modalità Online

## 4.1 Requisiti Backend

* Matchmaking
* Creazione stanza privata
* Lobby con invito amici
* Stato partita sincronizzato realtime
* Sistema anti-cheat (server authoritative)

Tecnologia suggerita:

* WebSocket per realtime
* Backend Node.js / Kotlin / Firebase
* Database: PostgreSQL / Firebase

---

## 4.2 Sincronizzazione

Il server deve:

* Validare le mosse
* Gestire turni
* Impedire cheat
* Gestire timeout turno (es. 30 secondi)

# 6️⃣ Logica Modalità Coppie

## 6.1 Team Assignment

Per 4 giocatori:

* Player 1 & 3 → Team A
* Player 2 & 4 → Team B

Il motore NON deve permettere:

* Comunicazione privata
* Visualizzazione carte compagno

---

# 7️⃣ Gestione Stati Edge Case

* Disconnessione online

  * Timeout 30 sec
  * Sostituzione con AI opzionale
* Fine turno con tutti pass
* Carte duplicate (impossibile, ma validazione server)
* Giocatore senza mosse possibili → auto pass

---

# 8️⃣ AI (Offline Mode)

Livelli:

### Easy

* Gioca prima combinazione valida

### Medium

* Gioca combinazione più bassa possibile

### Hard

* Strategia:

  * Conserva 2
  * Evita di liberare turno se avversario con 1 carta
