# MURLAN — UI Polish Instructions

## 1. Active Player Glow Effect + Action Buttons

### Glow effect
The pulsing glow is implemented in `useTurnPulse` inside
`components/GameShared.tsx` (or `lib/useTurnPulse.ts`).

- The glow must animate using a `withRepeat` + `withSequence` of two
  `withTiming` calls. Both the fade-in and fade-out legs must use the
  **same duration**: set both to **900ms**. This makes the pulse rise
  and fall at equal speed with no pause, producing a slow breathing
  effect. Remove any `easing` overrides — use the default linear easing
  so the speed is perfectly uniform in both directions.
- The animated `shadowRadius` must interpolate between **8** (dim) and
  **22** (bright). Do not go higher than 22 — it was previously too wide
  and spread beyond the card area.
- The animated `shadowOpacity` must interpolate between **0.35** and
  **0.85**.
- On web, the `boxShadow` blur radius must interpolate between **8px**
  and **20px** and the alpha between **0.35** and **0.85**.
- The glow animated style must be applied **only** to the `handSection`
  container — the View that wraps the card row. It must NOT be applied
  to the full game table, the PASSA button, the GIOCA button, or any
  parent View above the hand row. The shadow must visually appear only
  around the player's own cards.
- The `scaleStyle` zoom applied to the card row must interpolate between
  **1.0** and **1.02** maximum. No higher — this subtle scale combined
  with the glow is sufficient to communicate whose turn it is.

### PASSA and GIOCA buttons
- In `components/GameShared.tsx`, increase `SIDE_BTN_W` from **50** to
  **62** and the GIOCA button width from `SIDE_BTN_W + 4` to
  `SIDE_BTN_W + 6` (i.e. **68**). Update the `handAvailW` formula
  accordingly: `handAvailW = tableW - (SIDE_BTN_W + 8) * 2 - 8`.
- Increase the font size of the PASSA and GIOCA labels from their
  current value to **13px**, bold, with `letterSpacing: 0.5`.
- Do NOT change `CARD_H` — the buttons must remain the same height as
  the cards as per the existing layout constraint in `replit.md`.
- Update this in `GameShared.tsx` only. Both `app/game.tsx` and
  `app/(online)/game.tsx` inherit these constants automatically.

## 2. Card Selection Animation

The card selection "lift" animation when a player taps a card is
currently overshooting. Find the `withSpring` or `withTiming` call
that animates the card's vertical `translateY` when `selected` toggles.

- If using `withSpring`: replace it with `withTiming` using a duration
  of **160ms** and `Easing.out(Easing.quad)`. This removes all
  springiness and bounce entirely. The card simply slides up cleanly.
- The selected `translateY` offset must be **-10** (ten pixels upward).
  If it is currently larger (e.g. -16 or -20), reduce it to -10.
- If `withSpring` must be kept for design reasons, set its config to:
  `stiffness: 280, damping: 28, mass: 0.6`. This produces a very small
  overshoot of roughly 1–2px — noticeable but not trampoline-like.
- The deselect animation (card returning to baseline) must use the exact
  same duration and easing as the select animation so the motion feels
  symmetrical.
- Do not change card tap logic, selection state, or which cards are
  valid to select. Only change the animation parameters.

## 3. Exchange Announcement Overlay ("x gave card to y")

This is the `ExchangeAnnouncement` component in
`components/ExchangeAnnouncement.tsx`.

### Size
- The overlay card must have a `maxWidth` of **300** and `width: '80%'`.
  It is currently too wide. Reduce internal `padding` to **16px**
  vertically and **20px** horizontally.
- Reduce `CardView` renders inside it to **scale 0.65** using
  `transform: [{ scale: 0.65 }]` so the card images are compact.

### Layout
- Each exchange pair must render as a single horizontal row:
  `[Loser avatar] → [CardView small] → [Winner avatar]` for the
  card the loser gave, and below it:
  `[Winner avatar] → [CardView small] → [Loser avatar]` for the
  card the winner gave back.
- Use a thin horizontal separator (`height: 1`, `backgroundColor:
  Colors.border`, `marginVertical: 8`) between pairs if there are
  multiple (4-player game).
- Avatar initials circles: `width: 28, height: 28, borderRadius: 14`,
  `backgroundColor: Colors.feltLight`, initial letter in `Colors.gold`,
  `fontFamily: Rajdhani_700Bold`, `fontSize: 13`.
- The arrow between avatars and card: use the text character `→` in
  `Colors.textMuted`, `fontSize: 12`.

### Typography
- Title: "Scambio" in `Colors.gold`, `Rajdhani_700Bold`, `fontSize: 16`,
  `textAlign: 'center'`, `marginBottom: 8`.
- No subtitle or body text needed — the visual row is self-explanatory.
- If `bothJokersException`: replace rows with a single centered line:
  "Nessuno scambio — Jolly doppio 🃏" in `Colors.textSecondary`,
  `fontSize: 13`.

### Styling
- Container background: `rgba(3, 16, 8, 0.96)`.
- Border: `1px solid Colors.border` with `borderRadius: Radius.xl` (20).
- Apply `Shadow.gold` from `lib/theme.ts` to the card.
- The fade-in/out animation stays as-is — do not change timing.
- The overlay backdrop must be `Colors.overlay` at `zIndex: 150`.
  Do not increase zIndex — it must sit below the flying card animation
  layer (zIndex 300) per the existing T005 fix in `replit.md`.

## 4. "Stanza" (Waiting Room) Menu — Header Padding Fix

Open `app/(online)/room.tsx`. This is the waiting room screen shown
after creating or joining a room in online mode.

- The screen header (title + back button row) is being clipped at the
  top. Replace any hardcoded `paddingTop` or `marginTop` on the header
  container with `insets.top + Spacing.md` using `useSafeAreaInsets()`
  from `react-native-safe-area-context`. This is the same pattern used
  in `app/(online)/index.tsx` ("Con Amici") after the recent fix.
- The back chevron `<` button must have the same style as in "Con
  Amici": `position: 'absolute'`, `left: insets.left + Spacing.md`,
  vertically centered with the title. Do not use a separate header bar
  component — keep it inline as in the other screens.
- The screen title ("Stanza" or the room code) must use
  `fontFamily: Rajdhani_700Bold`, `fontSize: FontSize.xl` (22),
  `color: Colors.white`, `textAlign: 'center'` — identical to the
  "Con Amici" title style.
- Wrap the entire screen content in `MenuLayout` with
  `scrollable={true}` so long player lists (4 players + invite panel)
  can scroll, but the header stays above the scroll area and is never
  clipped by the safe area.
- The `InviteFriendsPanel` at the bottom must have a `maxHeight` of
  **180** with an internal `ScrollView` so it never pushes the "Inizia
  Partita" button off screen.

## 5. Shared Billboard / Game Table Header Design

The "billboard" is the central top area of the game table that shows
current round info, whose turn it is, and the last played combination
label. It currently looks different between `app/game.tsx` (offline)
and `app/(online)/game.tsx` (online).

### Decision
Use the **online game billboard** as the reference — it is more
complete (shows player names, emoji reactions, score). Bring its exact
markup, styles, and layout into `components/GameShared.tsx` as an
exported component called `GameBillboard`.

### What GameBillboard renders
- Room/round indicator top-left: "Manche X / Y" or "Partita" in
  `Colors.textMuted`, `fontSize: FontSize.xs`.
- Center: the current combo label (e.g. "Coppia di Re") or "— Tavolo
  libero —" when no combo is active. Use `Colors.gold`,
  `Rajdhani_700Bold`, `fontSize: FontSize.md`.
- Turn indicator below center: "Turno di [PlayerName]" or "Il tuo
  turno" (highlighted in gold when local player). `fontSize:
  FontSize.sm`, `Inter_400Regular`.
- The entire billboard must have `backgroundColor: 'transparent'` — it
  sits over the felt, not in a separate box.
- Height must equal `TOP_BAR_H` (40) as defined in `GameShared.tsx` —
  do not change this constant.

### How to apply
- In `app/game.tsx` (offline), remove the existing inline billboard
  markup and replace with `<GameBillboard ... />` passing the relevant
  props from `GameContext`.
- In `app/(online)/game.tsx`, do the same using props from
  `OnlineGameContext`.
- Props interface for `GameBillboard`:
  - `roundLabel: string` — e.g. "Manche 2 / 5" or "Partita"
  - `currentComboLabel: string | null` — null shows "— Tavolo libero —"
  - `currentTurnName: string` — name of the player whose turn it is
  - `isLocalPlayerTurn: boolean` — highlights the turn text in gold
- Do not move any emoji reaction logic into `GameBillboard`. Emoji
  reactions remain in the online game file only and are rendered
  separately above the billboard.
- Do not change `TOP_BAR_H`, `TABLE_M`, or any other layout constant
  in `GameShared.tsx` while doing this work.
