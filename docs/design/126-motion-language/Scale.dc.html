Springs or durations
A spring when the player caused it and is still touching it — a card picked up, dragged, released. Its arrival should answer the finger, and a duration cannot.
A duration for everything the table does on its own — a banner, a reveal, an opponent's play. These must be predictable and must line up with each other; springs drift apart under load.
Three springs were mis-tuned once and had to be fixed by hand. pickup is critically damped on purpose — it must not ring under the finger — and land overshoots about 7% once, which is the one bounce a dropped object earns.
Reduce motion is not "off". Travel is what goes; state change stays legible. A card that flew now cross-fades in place, and impactDelayMs() already returns 0 under reduced motion so the feedback fires immediately rather than waiting for a flight that never happens.
