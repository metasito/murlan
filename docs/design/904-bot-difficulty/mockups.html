Full-width segmented control below the name, not squeezed into the same line as the avatar — the row grows one line taller only when the seat is AI. All three options are visible and directly tappable (no cycling), each meeting the 44pt touch floor (TOUCH_TARGET_MIN). Segments are separated by Colors.border hairlines and sit on Colors.bgElevated, matching the existing pill's surface.

How this reads as a ladder, not a switch

Selection state is never colour alone shape + fill + label: a rising three-bar glyph (like a signal-strength icon) climbs left to right, filled solid on the selected segment and dimmed on the others, alongside the gold fill (Colors.gold) and a 2px Colors.goldLight top edge that only the selected segment carries. A colour-blind reader still sees which bar-height is "on," and a sighted reader gets the ladder metaphor for free from the glyph shape.

Container Border Colors.border, radius Radius.md (12), background Colors.bgElevated — same materials as the pill it replaces.
Selected segment Fill Colors.gold, text/glyph Colors.bg (dark-on-gold, the same contrast pairing as MenuButton's primary variant), top edge Colors.goldLight.
Unselected segment Text Colors.textSecondary, glyph bars Colors.textMuted — dim, not hidden, so all three labels stay legible before a choice is made.
Accessibility Container is a radiogroup; each segment a radio with accessibilityState={{ selected }} and a full-word accessibilityLabel ("Easy", "Normal", "Hard" — localized) — never abbreviated for the screen reader even though the on-screen glyph is compact.
