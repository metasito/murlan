**Goal:** A tap lifts its card on the UI thread in the same frame, whatever the JS thread is doing. A played card is one view from the hand to the sweep. No card draws a masked `boxShadow`. The felt is an opaque layer. The lamp's cost is measured on the device before anything is changed for it. Every device gate reads a Release build.

**Architecture:**

- **Pile.** `PileLayer` (in `components/table/pile.tsx`) renders every play of the trick as one group keyed by the play, and every card in it keyed by card id. A group mounts at the throw and flies on plan 2's flight clock and pose. It then takes the mockup's beaten pose on the same views, is hidden when buried, and is swept on the same views. The groups are driven by a pure trick model (`components/table/trick.ts`).
- **Selection.** The selection is a shared value that the hand's tap gesture toggles on the UI thread. One `scheduleOnRN` per tap publishes it to a small external store (`useSyncExternalStore`). Only the leaves that show it subscribe: each hand card to its own membership, the hand's status line, and the GIOCA control. `GameTable` creates the store and never re-renders on a tap. `GameContext` and the two screens hold none.
- **Shadows.** Card shadows are four committed PNGs, generated from the shadow tokens by a pure rasterizer and drawn as unmasked images.
- **Device.** Three bench scenarios and their `GATES` entries extend plan 1's diagnostics. The stall rule, the JS probe and the Release-only verdict are plan 1's.

## What the source says (verified 2026-09-28 in this worktree and `C:/Users/roton/murlan/node_modules`, which this worktree resolves from)

**Box shadows.**

- `react-native/React/Fabric/Mounting/ComponentViews/View/RCTBoxShadow.mm:74-107` (`RCTGetOutsetBoxShadowLayer`) builds each outset shadow as a `CALayer` with a `shadowPath` and a `CAShapeLayer` mask (`:86-100`).
- `RCTViewComponentView.mm:1279-1297` adds one such layer per entry of the `boxShadow` list. `styleWouldClipOverflowInk` (`:894-901`) applies to a view with `overflow: hidden` that has a `boxShadow`, which `styles.card` is (`CardView.tsx:853-859`).

**Filter.** The iOS brightness filter (`RCTViewComponentView.mm:1201-1213`) is a `_filterLayer` the size of the view. It uses `compositingFilter = @"multiplyBlendMode"` and `zPosition = CGFLOAT_MAX`, so a filter on a group darkens everything under the group's bounds. Plan 5's contract (a per-card overlay, never a `filter`) holds.

**Skia `opaque` on iOS.** In @shopify/react-native-skia 2.12.0:

- `apple/SkiaUIView.mm:162-164` only stores `_opaque`;
- `apple/MetalWindowContext.mm:21` hard-codes `_layer.opaque = false`;
- the metal layer is `RNSkMetalCanvasProvider.mm:31` `[CAMetalLayer layer]`, added at `SkiaUIView.mm:74`.

`CAMetalLayer`'s own default is opaque. So a patch that only deletes line 21 would turn every other canvas in the app black. `SkiaUIView` must set the layer from `_opaque` on every canvas.

On Android the same prop is not a flag but a view swap: `SkiaBaseView.java:37-43` `setOpaque(true)` recreates the canvas as a `SkiaSurfaceView`, which ignores view opacity, transforms and transitions. So `opaque` is passed on iOS only.

The particle canvas (`components/table/particleLayer.tsx:119`) stays transparent: it draws sparks over the felt and the cards, so an opaque layer would black out the table under it.

- `react-native-worklets/src/featureFlags/staticFlags.json` has `"IOS_DYNAMIC_FRAMERATE_ENABLED": true`.

```ts
function decode(buf: Buffer) {
  let p = 8, width = 0, height = 0;
  const idat: Buffer[] = [];
  while (p < buf.length) {
    const len = buf.readUInt32BE(p);
    const type = buf.toString("ascii", p + 4, p + 8);
    const data = buf.subarray(p + 8, p + 8 + len);
    if (type === "IHDR") [width, height] = [data.readUInt32BE(0), data.readUInt32BE(4)];
    if (type === "IDAT") idat.push(data);
    p += 12 + len;
  }

  const rgba = new Uint8Array(width * height * 4);
  for (let y = 0; y < height; y++) {

    rgba.set(raw.subarray(y * (width * 4 + 1) + 1, (y + 1) * (width * 4 + 1)), y * width * 4);
```

```ts
  back: { w: CARD_BACK_W(1), h: CARD_BACK_H(1), layers: ShadowLayers.cardBack, lip: false, inset: 0 },
  glow: { w: CARD_W(1), h: CARD_H(1), layers: ShadowLayers.glow, lip: false, inset: GLOW_INSET },
};

const marginOf = (s: Spec) => Math.ceil(Math.max(...s.layers.map((l) => Math.abs(l.offsetY) + 1.5 * l.radius), s.lip ? stockLipHeight(s.h) : 0));

export function shadowFrame(kind: ShadowKind, w: number): { left: number; top: number; width: number; height: number } {
  const s = SPECS[kind];
  const k = w / s.w;
  const m = marginOf(s);
  return { left: -m * k, top: -m * k, width: (s.w + 2 * m) * k, height: (s.h + 2 * m) * k };
}

function coverage(W: number, H: number, x0: number, y0: number, w: number, h: number, r: number): Float32Array {
  const out = new Float32Array(W * H);
  for (let py = 0; py < H; py++) {
    for (let px = 0; px < W; px++) {
      let hit = 0;
      for (let sy = 0; sy < SAMPLES; sy++) {
        for (let sx = 0; sx < SAMPLES; sx++) {
          const x = px + (sx + 0.5) / SAMPLES - x0;
          const y = py + (sy + 0.5) / SAMPLES - y0;
          if (x < 0 || y < 0 || x > w || y > h) continue;
          const cx = Math.min(Math.max(x, r), w - r);
          const cy = Math.min(Math.max(y, r), h - r);
          if ((x - cx) ** 2 + (y - cy) ** 2 <= r * r) hit++;
        }
      }
      out[py * W + px] = hit / (SAMPLES * SAMPLES);
    }
  }
  return out;
}

function blur(src: Float32Array, W: number, H: number, sigma: number): Float32Array {
  if (sigma <= 0) return src;
  const rad = Math.ceil(3 * sigma);
  const k = Array.from({ length: 2 * rad + 1 }, (_, i) => Math.exp(-((i - rad) ** 2) / (2 * sigma * sigma)));
  const sum = k.reduce((a, b) => a + b, 0);
  const pass = (a: Float32Array, dx: number, dy: number) => {
    const out = new Float32Array(W * H);
    for (let y = 0; y < H; y++) {
      for (let x = 0; x < W; x++) {
        let v = 0;
        for (let i = -rad; i <= rad; i++) {
          const xx = x + i * dx, yy = y + i * dy;
          if (xx >= 0 && yy >= 0 && xx < W && yy < H) v += a[yy * W + xx] * k[i + rad];
        }
        out[y * W + x] = v / sum;
      }
    }
    return out;
  };
  return pass(pass(src, 1, 0), 0, 1);
}

const rgb = (hex: string) => {
  const n = parseInt(hex.slice(1), 16);
  return [(n >> 16) & 255, (n >> 8) & 255, n & 255] as const;
};

export function rasterShadow(kind: ShadowKind, density = SHADOW_DENSITY): { width: number; height: number; rgba: Uint8ClampedArray } {
  const s = SPECS[kind];
  const m = marginOf(s);
  const W = Math.round((s.w + 2 * m) * density);
  const H = Math.round((s.h + 2 * m) * density);
  const at = (m + s.inset) * density;
  const bw = (s.w - 2 * s.inset) * density;
  const bh = (s.h - 2 * s.inset) * density;
  const r = cardRadius(s.w) * density;
  const paints = [...s.layers].reverse().map((l) => ({
    cov: blur(coverage(W, H, at, at + l.offsetY * density, bw, bh, r), W, H, (l.radius / 2) * density),
    color: rgb(l.color),
    alpha: l.opacity,
  }));
  if (s.lip) paints.push({ cov: coverage(W, H, at, at + stockLipHeight(s.h) * density, bw, bh, r), color: rgb(ShadowLayers.lip), alpha: 1 });
  const out = new Uint8ClampedArray(W * H * 4);
  for (let i = 0; i < W * H; i++) {
    let a = 0, cr = 0, cg = 0, cb = 0;
    for (const p of paints) {
      const pa = p.cov[i] * p.alpha;
      cr = p.color[0] * pa + cr * (1 - pa);
      cg = p.color[1] * pa + cg * (1 - pa);
      cb = p.color[2] * pa + cb * (1 - pa);
      a = pa + a * (1 - pa);
    }
    out[i * 4] = a > 0 ? cr / a : 0;
    out[i * 4 + 1] = a > 0 ? cg / a : 0;
    out[i * 4 + 2] = a > 0 ? cb / a : 0;
    out[i * 4 + 3] = a * 255;
  }
  return { width: W, height: H, rgba: out };
}
```

- The CSS list paints front to back, so the layers are composited in reverse, with the lip last, on top.
- The CSS blur radius is two sigma, so `sigma = radius / 2`.
- A 3-sigma cut leaves less than 1/255 at every opacity here.

```js
export function encodePng({ width, height, rgba }) {
```

```js
#!/usr/bin/env node
import { readFileSync } from "node:fs";
import { inflateSync } from "node:zlib";
import { isInvokedDirectly } from "../../scripts/lib/entry.mjs";

const EDGE = 0.06;
const MAX_EDGE_BLACK = 0.5;
const MAX_BLACK = 0.05;

export function decodePng(buf) {
  let p = 8, width = 0, height = 0, type = 0;
  const idat = [];
  while (p < buf.length) {
    const len = buf.readUInt32BE(p);
    const kind = buf.toString("ascii", p + 4, p + 8);
    const data = buf.subarray(p + 8, p + 8 + len);
    if (kind === "IHDR") { width = data.readUInt32BE(0); height = data.readUInt32BE(4); type = data[9]; }
    if (kind === "IDAT") idat.push(data);
    p += 12 + len;
  }
  const bpp = type === 6 ? 4 : 3;
  const raw = inflateSync(Buffer.concat(idat));
  const stride = width * bpp;
  const out = Buffer.alloc(height * stride);
  for (let y = 0; y < height; y++) {
    const f = raw[y * (stride + 1)];
    for (let x = 0; x < stride; x++) {
      const v = raw[y * (stride + 1) + 1 + x];
      const a = x >= bpp ? out[y * stride + x - bpp] : 0;
      const b = y > 0 ? out[(y - 1) * stride + x] : 0;
      const c = x >= bpp && y > 0 ? out[(y - 1) * stride + x - bpp] : 0;
      const pa = Math.abs(b - c), pb = Math.abs(a - c), pc = Math.abs(a + b - 2 * c);
      const paeth = pa <= pb && pa <= pc ? a : pb <= pc ? b : c;
      out[y * stride + x] = (v + [0, a, b, (a + b) >> 1, paeth][f]) & 255;
    }
  }
  const rgba = new Uint8Array(width * height * 4);
  for (let i = 0; i < width * height; i++) {
    for (let k = 0; k < 3; k++) rgba[i * 4 + k] = out[i * bpp + k];
    rgba[i * 4 + 3] = bpp === 4 ? out[i * bpp + 3] : 255;
  }
  return { width, height, rgba };
}

export function feltPixels(buf) {
```

```ts
import type { Combination } from "../../lib/game/gameEngine.ts";

import type { FlightSpec } from "./useFlightClock.ts";

export interface TrickPlay { key: string; combo: Combination; playedBy: number; spec: FlightSpec }
export interface Trick {
  plays: readonly TrickPlay[];
  swept: { plays: readonly TrickPlay[]; to: { dx: number; dy: number } } | null;
}
export type PlayPose = "top" | "beaten" | "buried";

export const EMPTY_TRICK: Trick = { plays: [], swept: null };

export function throwInto(t: Trick, play: TrickPlay): Trick {
  if (t.plays.at(-1)?.key === play.key) return t;
  return { ...t, plays: [...t.plays, play] };
}

export function sweepTrick(t: Trick, to: { dx: number; dy: number }): Trick {
  return { plays: [], swept: t.plays.length === 0 ? t.swept : { plays: t.plays, to } };
}

export function sweepDone(t: Trick): Trick {
  return t.swept === null ? t : { ...t, swept: null };
}

export function clearTrick(t: Trick): Trick {
  return t.plays.length === 0 ? t : { ...t, plays: [] };
}

export function playPose(plays: readonly TrickPlay[], i: number): PlayPose {
  const depth = plays.length - 1 - i;
  return depth === 0 ? "top" : depth === 1 ? "beaten" : "buried";
}
```

```ts
import { useSharedValue, type SharedValue } from "react-native-reanimated";
import { scheduleOnRN, scheduleOnUI } from "react-native-worklets";

export interface SelectionStore {
  get(): readonly string[];
  set(ids: readonly string[]): void;
  subscribe(fn: () => void): () => void;
}

export function selectionStore(): SelectionStore {
  let ids: readonly string[] = [];
  const subs = new Set<() => void>();
  return {
    get: () => ids,
    set: (next) => {
      if (next === ids) return;
      ids = next;
      for (const fn of subs) fn();
    },
    subscribe: (fn) => {
      subs.add(fn);
      return () => {
        subs.delete(fn);
      };
    },
  };
}

export function useSelected<T extends boolean | number | readonly string[]>(store: SelectionStore, pick: (ids: readonly string[]) => T): T {
  return useSyncExternalStore(store.subscribe, () => pick(store.get()));
}

  "worklet";

  handIds: readonly string[];
  one: boolean;
  onCue: (on: boolean) => void;

  const pressed = useSharedValue<string | null>(null);
  const [store] = useState(selectionStore);
  const cue = useRef(onCue);
  useEffect(() => {
    cue.current = onCue;
  }, [onCue]);
  const [publish] = useState(() => (_id: string, on: boolean, next: string[]) => {
    store.set(next);
    cue.current(on);
  });
  const reset = useCallback((next: string[]) => {
    sel.value = next;
    store.set(next);
  }, [sel, store]);
  const prevHand = useRef(handIds);
  useEffect(() => {
    const cur = store.get();
    const next = afterHandChange(cur, prevHand.current, handIds);
    prevHand.current = handIds;
    if (next.length !== cur.length) reset(next);
  }, [handIds, store, reset]);
  useEffect(() => {
    reset([]);
  }, [one, reset]);
  const tap = useCallback((id: string) => scheduleOnUI(applyTap, sel, id, one, publish), [sel, one, publish]);
  const clear = useCallback(() => reset([]), [reset]);
  const picks = useMemo(() => ({ sel, pressed, store, publish }), [sel, pressed, store, publish]);
  return { picks, tap, clear };
```

```ts
export interface DealLeg { leaveMs: number; flightMs: number }

export function assignDealSlots(legs: readonly DealLeg[]): number[][] {
  const order = legs.map((_, i) => i).sort((a, b) => legs[a].leaveMs - legs[b].leaveMs);
  const slots: number[][] = [];
  const freeAt: number[] = [];
  for (const i of order) {
    const s = freeAt.findIndex((t) => t <= legs[i].leaveMs);
    const end = legs[i].leaveMs + legs[i].flightMs;
    if (s === -1) {
      slots.push([i]);
      freeAt.push(end);
    } else {
      slots[s].push(i);
      freeAt[s] = end;
    }
  }
  return slots;
}
```

```js
const THROW_WINDOW_MS = 600;
const MIN_THROWS = 10;
const MIN_COVER = 0.8;
const PAIRS = 4;
const FROZEN_MIN_HZ = 115;
const SWAYING_MAX_HZ = 100;
const OPAQUE_GAIN_HZ = 5;
const MIN_CLEAR_STALLS = 4;

export function medianHz(rows) {
  const byWindow = new Map();
  for (const r of rows) {
    if (r.k !== "frame") continue;
    const w = Math.floor(r.t / 1000);
    byWindow.set(w, [...(byWindow.get(w) ?? []), r.dt]);
  }
  const hz = [...byWindow.values()].map((dts) => 1000 / median(dts));
  return hz.length ? Math.round(median(hz)) : 0;
}

const startsIn = (r, w) => r.t - r.dt >= w && r.t - r.dt <= w + THROW_WINDOW_MS;
const frameMs = (rows, from, to) => rows.filter((r) => r.k === "frame" && r.t > from && r.t <= to).reduce((s, r) => s + r.dt, 0);

function throwStalls(rows) {
  const throws = times(rows, "trigger", "throw");
  const near = rows.filter((r) => (r.k === "frame" || r.k === "jsLag") && throws.some((w) => startsIn(r, w)));
  const b = burstStalls([...near, ...rows.filter((r) => r.k === "jsTicks")]);
  const cover = throws.length ? throws.reduce((s, w) => s + frameMs(rows, w, w + THROW_WINDOW_MS), 0) / (throws.length * THROW_WINDOW_MS) : 0;
  const metrics = { throws: throws.length, stalls: b.stalls, cover, jsTicks: b.jsTicks, hz: medianHz(rows) };
  return { pass: throws.length >= MIN_THROWS && cover >= MIN_COVER && b.jsTicks > 0 && b.stalls === 0, metrics };
}

function halves(rows, name) {
  const marks = (phase) => rows.filter((r) => r.k === "half" && r.name === name && r.phase === phase);
  return marks("start").flatMap((s) => {
    const e = marks("end").find((r) => r.i === s.i);
    return e ? [rows.filter((r) => r.t >= s.t && r.t <= e.t)] : [];
  });
}

export function lampVerdict(pairs) {
  return pairs.length > 0 && pairs.every((p) => p.frozen >= FROZEN_MIN_HZ && p.swaying <= SWAYING_MAX_HZ) ? "A" : "B";
}

export function opaqueVerdict(pairs) {
  if (pairs.length === 0) return "drop";
  const faster = pairs.every((p) => p.opaque.hz >= p.clear.hz + OPAQUE_GAIN_HZ);
  const clearStalls = pairs.reduce((n, p) => n + p.clear.stalls, 0);
  const opaqueStalls = pairs.reduce((n, p) => n + p.opaque.stalls, 0);
  return faster || (clearStalls >= MIN_CLEAR_STALLS && clearStalls >= 2 * opaqueStalls) ? "keep" : "drop";
}

function lampCost(rows) {
  const swaying = halves(rows, "swaying").map(medianHz);
  const pairs = halves(rows, "frozen").map(medianHz).map((frozen, i) => ({ frozen, swaying: swaying[i] ?? 0 }));
  const pass = pairs.length === PAIRS && pairs.every((p) => p.frozen > 0 && p.swaying > 0);
  return { pass, metrics: { outcome: lampVerdict(pairs), pairs } };
}

function feltOpaque(rows) {
  const measure = (part) => ({ hz: medianHz(part), stalls: burstStalls(part).stalls });
  const clear = halves(rows, "clear").map(measure);
  const pairs = halves(rows, "opaque").map(measure).map((opaque, i) => ({ opaque, clear: clear[i] ?? { hz: 0, stalls: 0 } }));
  const pass = pairs.length === PAIRS && pairs.every((p) => p.opaque.hz > 0 && p.clear.hz > 0);
  return { pass, metrics: { outcome: opaqueVerdict(pairs), pairs } };
}
```

**Checks that could pass without the property.**

- **Count independence** fails if any per-card shadow exists. Its floor is that the two tables differ in cards, and that every one of the seven scopes was seen, `sweep-cards` and `dealt-back` included.
- **The mount test** fails on a second mount, or an early unmount, of any played card, on a second `begin` for one key, or on a frame callback left active. Its floor is four closed rounds and more than four cards, under both motion settings.
- **The throw gate** cannot pass with fewer than 10 throws, frames covering under 80 % of the throw windows, or no JS ticks. A stall between throws is, by test, not a throw's.
- **The lamp and felt gates** cannot pass with a pair missing.
- **The opaque gate** cannot keep the patch without a measured gain in every pair; with no gain the patch is removed (Task 9).
- **The pixel check** fails a black felt, and its decoder is tested on all five PNG filters.
- **The Release rule** is plan 1's `verdict()`: a Metro-served bundle is unrun for every gate here.
- **The patch test** fails on a planted patch that lacks the removal.
- **The governor test** fails on a planted override.
- **The raster** is checked against an independent erf and against the browser.
- **No timing test re-derives its expectation.** `threadGates` uses literal rows; `dealSlots` uses its own sweep; `lampVerdict` uses literal fps.

## Design questions for the lead

1. **The beaten pose starts at the throw, not "when the next play lands".**
   - **Why:** the mockup's `play()` (`index.html:513-521`) turns `.cur` into `.prev` at the throw, with a 280 ms ease-out, and the owner kept every "follow the mockup" item.
   - **Assumed:** at the throw, with `Motion.beaten = 280` (`Motion.reduced.beaten = 0`). It sits outside the `Motion.duration` ladder because it is the mockup's figure, not a step on it; `motionMs` accepts it by name.
   - **On the other answer:** `PileLayer` computes the pose from the previous play's `landed`.
2. **The beaten shade replaces `pilePrevLayer`'s `opacity: 0.3`.** Today the old layer is 30 % opaque (`pile.tsx:1027-1030`). The design asks for brightness 0.6, so the cards are opaque and shaded.
   - **Assumed:** `Beaten.shade`, defined here exactly as plan 5 writes it. Plan 5 Task 1 skips its own definition and its eslint append.
3. **The mockup's cast shadow follows the lamp** (`index.html:67` `--shx/--shy`, updated at `:699`). The app has never done this, and the design's "one pre-rendered image per card size" cannot.
   - **Assumed:** static images. Following the lamp would mean offsetting each card's image by the lamp every frame, which needs its own ticket and its own bench cost.
4. **The shadow now scales with the card.** Today's blur radii are fixed points, so a card at 1.2× casts a 5.4 pt blur where it cast 4.5.
   - **Assumed:** the image scales. The table already scales as a whole, as the mockup does.
5. **The lip survives the lift.** Today `selected && Shadow.cardLifted` replaces the whole list, lip included (`CardView.tsx:714`).
   - **Assumed:** both images carry the lip, since it is the card's edge rather than a shadow.
6. **The selection's readers move into leaves, and `GameTable` never renders on a tap.** The design says "its own context". `GameTable`'s own render would re-render the seats and the pile that are not memoised, so the readers move out: `staged`, the GIOCA state and the exchange pick go to `PlayControl`, the hand label to `HandStatus`, and the GIOCA cues to `useGiocaCues`. Each subscribes to the store through `useSelected`. The cost is a larger Task 6; the alternative was memoising every sibling.
7. **The redraw test is inverted only under outcome A.** The caller asked for it inverted. Under B the mockup's endless sway is the spec and the cost is not player-visible, so the 570-of-600 test stays. The two asks conflict, and I resolved it by outcome.
8. **The Release bench build replaces the dev client on the phone** (same bundle id, free Apple ID). The next plain `ios:device` reinstalls the dev client through the `bench-` fingerprint.
9. **Resolved by plan 1: the Release rule, the JS probe and the tap gate are all plan 1's.** Plan 1's `verdict()` holds every gate to Release, and its `burstStalls` counts both threads. Its `tapBurst` covers what this plan's `tap-stalls` did, so `tap-stalls` is gone. What stays open is whether G1's `fastShare` (the share of 250 ms windows at 100 Hz or more) is the "80 % at 120 Hz" the lead decided; this plan takes plan 1's definition.
10. **A tap is RNGH's tap, simultaneous with the reorder pan, with `maxDuration` 60 s.** This keeps today's rule that a press however long is still a press (`hand.tsx:880-884`). The `Pressable` no longer takes touches for a hand card; assistive technology and the keyboard reach the same `applyTap` through `onActivate`.
11. **A pile card keeps its stock shadow image.** Plan 2's "the cards carry no shadow of their own" is read as the flight's lifted shadow, which plan 2 deleted. The mockup's `.card` draws its shadow on every card, the pile's included.
12. **Selection clears when the hand gains a card** (a deal, or the exchange's received card). One rule replaces seven `GameContext` clears and the online screen's ack- and manche-clears.
13. **One flight clock per play group, idle between flights.** Groups now persist, so each clock registers with `useFrameCallback(step, false)` and is active only from `begin` to its end. A settled group, or one mounted on resume, never arms. The upgrade, if many groups ever fly at once, is one shared clock for the trick.
14. **Design citation errors.**
    - `CardView.tsx:716` is `:714`.
    - `RCTBoxShadow.mm:73-107` is `:74-107`.
    - "The felt layer opaque" needs a native patch: skia 2.12.0's `opaque` never reaches the iOS layer (`SkiaUIView.mm:162-164`, `MetalWindowContext.mm:21`).
    - The design's "the lamp shadow" is not drawn anywhere in the app (question 3).
15. **JS cannot tell a Release build from a Debug one at run time.** RN 0.86.3 exports no such constant: `RCTPlatform.mm:67` carries only `isTesting`, and `RCTDevSettings` exports no flag.
    - **Assumed:** Release is proven at build time, by `ios-bench.yml` and the `bench-` fingerprint, and at run time by plan 1's `build` row (`__DEV__` and the bundle's `scriptURL`).
    - **On the other answer:** an Info.plist key set from `$(CONFIGURATION)` plus a small native module, which is native code this plan does not add.
16. **The opaque felt stays only on a measured gain.**
    - **Assumed thresholds:** 4 pairs of 20 s. Keep the patch if every pair is at least 5 Hz faster with the felt opaque. Also keep it if the clear halves have at least 4 stalls in total and at least twice the opaque halves'.
    - **Otherwise:** Task 9 removes the patch and the upstream issue is not filed.
    - The lead may prefer another margin.
17. **The resize check is a portrait trip.** `felt-opaque.yaml` rotates to PORTRAIT and back to LANDSCAPE_LEFT, because Maestro has no window resize. The black-felt bug came from a resize (`SkiaBaseView.java:37-43` on Android, the layer's `opaque` on iOS), and a rotation is the resize a phone makes.
18. **Plan 2's `CARD_W * cardScale` is a bug.** `CARD_W` is a function of the scale (`cardFaceModel.ts:40`), so the product is `NaN` in JS and a type error in tsc. This plan writes `CARD_W(cardScale)`; plan 2 should be fixed at the source.
19. **A long recording would overflow plan 1's recorder.** `FrameProbe` flushes only at `frames(false)`, and the outbox holds 5000 rows, so a whole manche recorded at once (about 9000 frames) would drop rows and fail on `dropped`. `throw-stalls` therefore records 700 ms per throw, and each 30 s lamp half (about 3600 frames) stays under the cap. If plan 1 raises the cap or flushes `FrameProbe` periodically, the windows could be one span.
