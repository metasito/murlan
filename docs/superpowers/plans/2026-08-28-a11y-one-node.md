# A labelled control exposes one accessible node — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the invariant enforced rather than remembered — a labelled
control with a reachable child fails the suite, and all 55 existing ones are
fixed.

**Architecture:** A JSX tag tokeniser added to the existing
`tests/helpers/sourceScan.ts`, a node-suite scan built on it that fails by
default with a short reasoned exception list, one browser assertion reading
Chromium's own accessibility tree, and the fixes themselves — `MenuButton`
first, since every menu screen's buttons are instances of it.

**Tech Stack:** node:test with TypeScript type stripping, Playwright (CDP
`Accessibility.getFullAXTree`), Jest + `@testing-library/react-native` for the
native suite, React Native / react-native-web.

**Spec:** `docs/superpowers/specs/2026-08-28-a11y-collapse-scan-design.md`

## Global Constraints

- **Default is no comment.** Four things earn one: an invisible constraint, a
  *why* where the obvious approach is wrong, a contract the types cannot carry,
  a pointer to the authority. Never explain the defect being fixed — that is
  the commit message's job.
- **No bare literals** for colour, radius, font size, spacing or timing.
- **Every user-facing string goes through `t()`**, keyed in all three locales.
  `locales/en.ts` is the source of truth; a missing key in `it.ts` or `sq.ts` is
  a compile error.
- **Hiding is spelled `{...a11yHidden()}`** from `lib/a11y.tsx`, never
  `accessibilityElementsHidden` by hand — the helper emits the `aria-*` twin
  that react-native-web needs.
- **Commit by pathspec** (`git add -- <files>`), never `git add -A`.
- The invariant's wording in `CLAUDE.md` is normative and must end up matching
  what the checks actually enforce.

Brace-aware, mirroring `enclosingTag`'s existing scan direction:

```ts
export interface JsxTag {
  name: string;
  isClose: boolean;
  selfClose: boolean;
  start: number;
  end: number;
  text: string;
}

/** Every JSX tag in `source`, in order. Brace-aware: `style={{…>…}}` is one tag. */
export function jsxTags(source: string): JsxTag[] {
  const out: JsxTag[] = [];
  for (let i = 0; i < source.length; i++) {
    if (source[i] !== "<") continue;
    const isClose = source[i + 1] === "/";
    const name = /^[A-Za-z][\w.]*/.exec(source.slice(i + (isClose ? 2 : 1)));
    if (!name) continue;
    let depth = 0;
    let end = -1;
    for (let j = i; j < source.length; j++) {
      const c = source[j];
      if (c === "{") depth++;
      else if (c === "}") depth--;
      else if (c === ">" && depth === 0) {
        end = j;
        break;
      }
    }
    if (end === -1) continue;
    const text = source.slice(i, end + 1);
    out.push({ name: name[0], isClose, selfClose: text.endsWith("/>"), start: i, end, text });
    i = end;
  }
  return out;
}
```

- [ ] **Step 3: Implement**

The label `Text` takes `{...a11yHidden()}`. `icon` arrives already built from
the caller, so it is wrapped rather than modified:

```tsx
{icon ? <View {...a11yHidden()}>{icon}</View> : null}
<Text
  {...a11yHidden()}
  style={[styles.label, labelStyles[variant], sizeLabelStyles[size]]}
  numberOfLines={1}

```

Leave `hintProps.node` reachable: `aria-describedby` resolves against it by id,
and hiding the target is how a description silently stops being announced.

### Task 9: The browser confirms it, on the tree itself

**Files:**
- Create: `tests/e2e/oneAccessibleNode.spec.ts`

**Interfaces:**
- Consumes: `test` from `tests/e2e/fixtures`, `openApp` from `tests/e2e/helpers/navigation`.

- [ ] **Step 1: Write the failing test**

The scan reads props; this reads what Chromium built from them. `getByText`
and `toMatchAriaSnapshot` were both tried in #393 and both stayed green against
a seeded child — the full AX tree is the one thing that distinguishes the
shapes.

```ts
const SCREENS = ["/lobby", "/rules"];

for (const screen of SCREENS) {
  test(`every named control on ${screen} is a leaf`, async ({ page, baseURL }) => {
    await openApp(page, baseURL!);
    await page.goto(`${baseURL}${screen}`);
    const cdp = await page.context().newCDPSession(page);
    await cdp.send("Accessibility.enable");
    const { nodes } = (await cdp.send("Accessibility.getFullAXTree")) as {
      nodes: { nodeId: string; role?: { value: string }; name?: { value: string };
               ignored?: boolean; childIds?: string[] }[];
    };
    const byId = new Map(nodes.map((n) => [n.nodeId, n]));
    const named = (n: typeof nodes[number]) => !n.ignored && !!n.name?.value?.trim();

    const offenders: string[] = [];
    for (const n of nodes) {
      if (n.role?.value !== "button" && n.role?.value !== "radio") continue;
      const stack = [...(n.childIds ?? [])];
      while (stack.length) {
        const c = byId.get(stack.pop()!);
        if (!c) continue;
        if (named(c)) offenders.push(`${n.role.value} "${n.name?.value}" -> ${c.role?.value} "${c.name?.value}"`);
        stack.push(...(c.childIds ?? []));
      }
    }
    expect(offenders).toEqual([]);
  });
}
```
