## Notes

1. **Access**: `gh api` and `curl api.github.com` returned 403 for `actions/*` and other action repos ("GitHub access to this repository is not enabled for this session"). `github.com/<repo>/releases` and `github.blog` are also refused by proxy policy. The `add_repo` tool offered only git-level read access, and API access would need push-level credentials, which I did not request. So `gh api releases/latest` and release-note bodies were NOT retrieved. Substitutes used: `git ls-remote --tags` and blobless bare clones (tags, peeled SHAs, commit dates), `raw.githubusercontent.com` (action.yml runtime, READMEs, runner-images README), and commit subjects between the pinned and latest tags.
2. **Release dates**: the dates above are commit dates of the tag, not GitHub `published_at`.
3. **"Latest"** is the highest GA semver tag found by `sort -V` of tags, not GitHub's `releases/latest` flag. No prerelease tags (beta, rc, node20 branches) were counted as latest. Repos with `-node20`/`-beta` tags: upload-artifact, download-artifact, cache, checkout (v2-beta, v6-beta).
4. **Node 20 deprecation** (WebSearch result, not opened on github.blog directly): GitHub changelog post 2025-09-19 "Deprecation of Node 20 on GitHub Actions runners" (https://github.blog/changelog/2025-09-19-deprecation-of-node-20-on-github-actions-runners/). Editor's notes in the post say the forced Node 24 default moved to June 16, 2026. Runner warnings quoted in GitHub issues say Node 20 is removed from runners on September 16, 2026. Treat both dates as secondhand until checked on the changelog page. Opt-in before the default: `FORCE_JAVASCRIPT_ACTIONS_TO_NODE24=true`. Every pinned action here except codeql (composite) still runs on node20 at its pin, so each must bump.
5. **Runner app**: latest tag `v2.338.2` (git ls-remote). Required minimums from READMEs: >= 2.327.1 for checkout v5+/setup-node v5+/cache v5+/setup-java v6, >= 2.231.0 for the cache service v2 migration.
6. **Summary of node20 pins**: checkout v4.4.0, setup-node v4.4.0, cache v4.3.0, upload-artifact v4.6.2, download-artifact v4.3.0, setup-java v4.9.1, expo 8.2.1 all declare `using: node20` at the pinned tag (verified in action.yml). android-emulator-runner v2.38.0 and expo 9.0.1 declare node24.
7. Not verified: the postgres `mirror.gcr.io` digest of the pinned tag resolves, but Docker Hub has no tag for it now; the pin still works if the mirror keeps the blob, but it does not track any tag.
