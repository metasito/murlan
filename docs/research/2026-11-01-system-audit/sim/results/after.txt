Instruments (the port, sim/repro/):
- srv/lib.ts RedisTap replaces NotifyTap as the cluster instrument: it reads the adapter's pub/sub
  (public and private channels: FETCH_SOCKETS, server-side emits, every response), the adapter
  stream (room broadcasts) and every instance's inbox stream, from the tap's start. Positive
  controls every script asserts before reporting a zero: both adapters' heartbeats heard, both
  inboxes' boot entries read, and (exp2) a FETCH_SOCKETS the harness publishes itself, which both
  instances answer on the tap. NotifyTap now throws if its Postgres channel is silent for 12 s.
- srv/lib.ts secretsInStore / secretsInTables: exact-value search for every cookie, session id and
  ticket the harness holds, across every message heard, every key and value in the store, and
  every text/json column; positive control: the session table's own sid column must be found.
- srv/exp-p2.ts blackholes all of instance A's Redis connections through the lib.ts TCP proxy
  (the sim/repro/db/proxy.ts pattern: bytes stop both ways, sockets stay open, new flows pass).
- load.sh: counts extended-protocol statements ("execute <name>:") as well as simple ones, and
  sends one control pg_notify the count must see before it reports pg_notify per move.
- srv/lib.ts scrapeMetrics: /metrics with the instances' bearer token; a metric counts as exported
  when its # TYPE line is served.
